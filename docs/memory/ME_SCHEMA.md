# Me schema

`config/me.example.json` is the dependency-free, fictional, editable sample consumed by `MeProfile.from_json_file`. It contains identity, names, languages/timezone, relationship conventions, communication, habits/interests/projects, privacy classification, stream-allowed fields, and never-public fields. No real private facts are included. The original YAML example remains as a human-readable reference.
